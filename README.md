# Mex Usage

```
mex create <directory-path>
mex open <file-path>
mex remove <file-path>
```



# Live TeX Instructions
* Install MacTex
* Claim file ownership
    `sudo chown -R <username> /usr/local/texlive`
* Add "/usr/local/texlive/2024/bin/universal-darwin/" to $PATH
    `set -xg PATH /usr/local/texlive/2024/bin/universal-darwin/ $PATH`
